BUILD TỪ THƯ MỤC HIỆN TẠI

Toàn bộ mã và payload cần thiết đã ở trong repository HeroControl.
Không cần chép data menu new, dump.cs, UnityFramework hoặc DummyDll lên GitHub.
Không cần Theos hoặc XcodeGen. Sau khi có commit mới:
    git push origin main

Chọn lượt Build HeroControl TIPA mới nhất, chờ tất cả bước kiểm tra qua.
Artifact HeroControl-TIPA-diagnostics có .tipa, SHA-256 và signing-report.json.
Telegram gửi sau kiểm thử nếu hai GitHub Secrets đã được cấu hình.

BUILD TRÊN MAC

Cần Xcode đầy đủ, SDK iPhoneOS, Simulator iOS 17+ và Python 3.10+.
    python3 scripts/validate-project.py
    python3 scripts/verify-runtime-payload.py
    python3 scripts/source-manifest.py
    python3 -m unittest discover -s tests -p 'test_*.py'
    bash scripts/build-tipa.sh
    bash scripts/test-simulator.sh

Kết quả: dist/HeroControl.tipa. Build riêng project Xcode chỉ tạo UI;
script đóng gói thêm backend/helper, bridge, overlay và adapter game.
Nếu chọn sai Xcode:
    sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer

Backend tùy chọn:
    bash scripts/build-tipa.sh --backend /absolute/path/HeroBackend.dylib
Backend phải là Mach-O arm64/iPhoneOS, đủ ba symbol C ABI. Backend riêng cần
triển khai action runtime để dùng cài/gỡ adapter; dependency không được tự gom.

CÀI VÀ THỬ

Đọc CAP_NHAT_0.10.1.txt. Tắt nút nổi cũ trước khi cài đè.
Mở game vào sảnh, quay lại Hero Control, bấm Cài / cập nhật adapter game.
Đóng hoàn toàn game rồi mở lại; kiểm tra adapter và thử từng nhóm trong trận tập.
Nút nổi chuyển cấu hình khi chạy; hoặc bấm Áp dụng. Nếu game bị tạm dừng ở nền,
vào game rồi quay lại để nhận xác nhận cùng revision/session.

Adapter cần bộ nạp tweak tương thích của jailbreak và chính sách chữ ký cho
phép nạp dylib. Helper chỉ cài thư viện/filter vào thư mục bộ nạp đã tồn tại;
không tự cài jailbreak, trust cache hoặc sửa entitlement game. Không sửa các
file HeroSkin gốc. Chưa active thì việc chép file chưa chứng minh nạp thành công.
Gỡ adapter từ app rồi mở lại game để xóa hook khỏi bộ nhớ; nhật ký được giữ lại.

Nguồn ảnh/minimap là sprite/hệ thống game thật. Truy vấn tố cáo dùng giao thức
donor theo người chơi đã thu thập; chưa chứng minh lấy được mọi bản ghi máy chủ.
Xuất chẩn đoán có runtime, runtimeDiagnostics, phản hồi gốc và dữ liệu lịch sử.
Xem phase/code/helperError khi adapter chưa phản hồi.

CẤU TRÚC

HeroControl/              SwiftUI, profile/revision, C ABI và chẩn đoán/runtime
BackendSDK/               Backend/helper root và bộ đọc bộ nhớ ngoài
Overlay/                  Nút nổi, đồng bộ cấu hình và worker ngoài
Runtime/GameRuntime.mm    Adapter trong game, kiểm tra UUID/mẫu lệnh, gọi Lua
Runtime/Runtime.lua       Đồng bộ cấu hình, danh mục skin và dữ liệu tố cáo
Runtime/Payload/          Hai patch + Lua tham khảo và manifest nguồn
Runtime/RuntimeInstaller.h Cài/gỡ, cấu hình và trạng thái adapter
Signing/                  Entitlement yêu cầu; cần xác minh cấp quyền trên máy
scripts/                  Build, kiểm tra, import, đóng gói và source manifest
HeroControlTests/         XCTest về cấu hình, xác nhận và dữ liệu giao tiếp
tests/                    Kiểm thử Python không gửi mạng

Khi sửa nguồn, cập nhật manifest trước khi commit:
    python3 scripts/source-manifest.py --write

Chỉ khi muốn nhập lại tài liệu gốc:
    python3 scripts/import-runtime-reference.py "/path/to/data menu new"
Lệnh này chỉ đọc tài liệu tham khảo và ghi Runtime/Payload trong dự án.
