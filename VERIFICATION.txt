HERO CONTROL 0.2.3 — Kiểm tra đã thực hiện trong môi trường Windows:

- Cú pháp Swift của app, XCTest và công cụ kiểm thử giao thức bằng tree-sitter-swift.
- Project OpenStep PBX: đọc thành công bằng parser pbxproj, đủ 2 target.
- 41 object ID trong PBX: duy nhất, không có tham chiếu mất.
- Shared scheme XML: hợp lệ, tham chiếu đúng app target và test target.
- Info.plist: đọc được bằng plistlib.
- 13 khóa công tắc và khóa camera: đối chiếu danh sách cấu hình đã phân tích.
- 3 symbol C ABI: khớp giữa bộ nạp Swift, header và backend ví dụ.
- Cả 4 script shell: qua bash -n.

Chưa thực hiện:

- Xcode type checking/compilation/linking.
- Chạy 9 bài XCTest trên iPhone Simulator.
- Chạy ứng dụng trên iPhone XR hoặc thử trình cài đặt của người dùng.
- Kết nối libkrw/helper và áp dụng chức năng trong game.

Workflow GitHub Actions đã được viết để build và chạy XCTest nhưng chưa
được đẩy lên repository hay kích hoạt từ phiên làm việc này.

Đây là kiểm tra cấu trúc/cú pháp, không phải bằng chứng rằng app đã build
hay rằng các chức năng game hoạt động. Bản bàn giao có backend chẩn đoán,
chưa có game adapter.

Bản 0.2: thêm kiểm tra ABI native trên runner macOS qua build-diagnostics.sh.
Việc nạp dylib/provider và đọc header chỉ được xác minh khi chạy trên thiết bị.

Bản 0.2.1: sửa @(!apply) -> boolean JSON tường minh; thêm kiểm tra CFBoolean
và kiểm thử backend native -> bộ giải mã Swift production trên runner macOS.
Các kiểm thử macOS/Simulator chưa được chạy từ môi trường Windows này.

Bản 0.2.2: khắc phục async protocol dispatch của exchangeTrace. Xóa default
implementation trả nil, khai báo async tường minh trong actor, thêm kiểm thử
qua cả concrete type lẫn protocol existential. Giữ nguyên kiểm thử trace.

Bản 0.2.3: phân giải jailbreak root qua API/link/tên thư mục RootHide.
